## Javascript

* Use pnpm for package management
* Should be a React frontend built with NextJS
* Should be written in Typescript
* Use BiomeJS or Prettier for formatting/linting
* Use Jest for testing
* Run end-to-end tests with Playwright
* Should use shadcdn/tailwind for styling/components
* For querying backends, use tan stack query to do query caching, on top of an OpenAPI backend in a type safe way, generated from the OpenAPI schema if available
* Use openapi-ts to generate frontend clients: https://github.com/hey-api/openapi-ts
* Use Framer motion for animations
* Use assistant-ui for AI/Chat/Search UI components: https://www.assistant-ui.com/docs/getting-started
* Use TipTap for text editors
* For data visualizations/charts, use Tremor: https://tremor.so/docs/getting-started/installation
* For more complicated components like an Org Chart, use Prime React: https://primereact.org/organizationchart/
* Use Zustand for state management
